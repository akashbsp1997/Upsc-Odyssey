# UPSC Odyssey + Study Plan

- `index.html` is the whole app: UPSC Odyssey (180 days of campaigns) plus the 📅 Plan button (180-day subtopic plan, reschedule, spaced revision, quiz, answer writing, prompts for Claude).
- `study-plan-only.html` is the Plan section on its own.

## Host it (free)
Upload the files in this folder to GitHub Pages, Netlify or Cloudflare Pages, then open the link on each phone.
- iPhone: Safari, Share, Add to Home Screen.
- Android: Chrome, menu, Install app.
Everything works offline after the first load.

## Limits
- Progress is stored in each browser. Cross-device sync only works for the version published inside Claude; use Export backup (Plan, Progress and backup) to move data.
- Opening index.html straight from a file does not work offline caching; host it.
